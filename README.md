# Comandos Linux

Material de estudo com os principais comandos de Linux, organizado por tema e direcionado para quem quem está começando no terminal e na área de bioinformática.

> 🚧 Em construção: este repositório está sujeito a atualizações.

## Conteúdo

- 📄 [Comandos Linux](comandos-linux.md): documento principal

### O que tem no documento

- **Comandos mais usados:** os essenciais do dia a dia
- **Navegação:** `pwd`, `ls`, `cd`
- **Criar, copiar e mover:** `mkdir`, `touch`, `cp`, `mv`, `rm`
- **Ver conteúdo:** `cat`, `head`, `tail`, `less`, `wc`, `file`
- **Buscar:** `grep`, `find`, `locate`, `history`
- **Sistema:** `df`, `du`, `top`, `whoami`, `man`
- **Combinar comandos:** pipes (`|`) e redirecionamento (`>`)
- **Servidor:** `ssh`, `scp`, `tmux`

Não tem Linux instalado? Dá para praticar no navegador com o [JSLinux](https://bellard.org/jslinux/), de Fabrice Bellard.
